# ![accretion_256](https://github.com/user-attachments/assets/cce38213-2870-4472-a533-6ccab520c0dc) Accretional

Accretional is an early stage startup in San Francisco working on a new kind of cloud platform.

To check out some of our public plans or docs, visit our [public planning repository](https://github.com/accretional/.github/tree/main/planning) - here's a [recent example](https://github.com/accretional/.github/blob/main/planning/13-4-2026.md)

To see our past work, check out our open source site site generator project at [statue.dev](https://statue.dev), visit our [website](https://accretional.com), join our [subreddit](https://reddit.com/r/accretional), or visit our [discord](https://discord.gg/accretional). Most of our 2024-25 projects are on ice while we work on a new IDE and toolset using [Anyserver](https://github.com/accretional/anyserver)

Brilliant 1.0 is our container-based, serverless remote IDE and developer sandbox that you can use to securely develop with agents on vscode instances that start when you connect to them over an authenticated websocket - test environment at [brilliant.mplode.dev](https://brilliant.mplode.dev) <img width="3450" height="2026" alt="image" src="https://github.com/user-attachments/assets/0f299bff-ad30-426f-a383-a81a20adde36" />

We are now building a new stack of developer tools and products that improve on this design, and move off vscode as a dependency, but make it still possible to use it in an embedded view. The project we are using as the base of this stack/UI is called [Anyserver](https://github.com/accretional/anyserver), and it's meant to make it easier to interoperate between the large number of tools and projects we've been building for the last couple years:
