# Notes / Planning Documents

Dumping notes and planning docs here to help us coordinate / track / share them and use them in context engineering.

## LLM explanations

Also including explanations eg 13-4-2026-4.6opus-explanation.md where I have an LLM try to analyze it with a prompt like 

```

Analyze this github startup note extensively (animation included as screenshot rather than video). Be extremely thorough, go deep

```

And then continually reprompt it with "keep going" or "continue" to extract useful subtext/explanations and try to reasonably cover all the material.

The goal here is to model how strong models will understand / parse these docs since we will likely keep them in context for certain work, and it probably also helps model how humans could interpret them.

Also, sharing the actual output to provide explanations for the plans using strong models for free to people who might be interested in that or inclined to create them themsevles.

Hoping this will be useful for smaller models too, exploring the teacher pattern and COT caching to help them with inference while we work on building the "Accretional Center for smol LLMs Who Can't Run Inference Good and Who Wanna Learn to Do Other Stuff Good Too"
